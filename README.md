# 哔哩哔哩纯净模式

给哔哩哔哩**网页版**加一个开关：**按一下，页面只剩视频画面**——
进度条、音量条、弹幕设置栏、顶部导航、右侧推荐、下方评论区全部隐去；
**再按一下，全部原样回来。**

## 安装（Edge / Chrome）

1. 下载本仓库（`Code` → `Download ZIP`）并解压，或者直接 `git clone`
2. 打开 **`edge://extensions`**（Chrome 用 `chrome://extensions`）
3. 打开左下角 **「开发人员模式」**
4. 点 **「加载解压缩的扩展」**，选择**含 `manifest.json` 的那一层文件夹**

> ⚠️ 浏览器是**直接从该文件夹读取**扩展的（不是把代码复制进浏览器里），
> 所以**不要删除或移动**这个文件夹，否则扩展下次启动会失效。

装好后打开任意哔哩哔哩视频，**屏幕左缘中间**会出现一个半透明小按钮。

## 用法

| 操作 | 效果 |
|---|---|
| 点**左缘**按钮 / 按 `Alt+L` | 进入**全屏纯净模式**：自动进全屏 + 只剩视频画面 |
| 再点一下 / 再按 `Alt+L` / `Esc` | 退出全屏，页面全部恢复 |
| 纯净模式下按 `D` | 连**弹幕**一起隐掉 / 显回来（默认保留弹幕）|
| 纯净模式下按 `T` | 诊断：把视口顶部此刻可见的元素**描红 5 秒**并报出真实类名（用来钉死"藏不掉的那条"）|
| 移动鼠标 | 按钮浮出来，3 秒不动就隐掉，画面真的只剩视频 |
| `Alt+;` | 附赠：**熄屏听剧**——整页纯黑、视频继续播放，躺着听；`Esc` 退出 |

## 它是怎么做到"不挑类名"的

哔哩哔哩会改版、类名会变，所以**没有**硬编码一堆选择器。核心做法是：

> 找到视频元素，沿着它的**祖先链**往上走，把每一层里"不是祖先的那些兄弟节点"全部隐藏。

推荐区、评论区、顶栏、侧栏……全都是这条链之外的兄弟，于是自然消失；
不管页面怎么改版，这个结构关系都成立，所以基本不用维护。

**播放器内部也走结构判断**：同样只保留"视频的祖先链"和**弹幕层**，其余兄弟全隐。
所以控制条、进度条、顶部工具栏、退出叉……**都不需要知道它们的类名**。
两个保护：容器里若装着弹幕层就不连坐隐藏；弹幕层本身永远保留。

CSS 只作为兜底与收尾（属性子串匹配）：

```css
[data-bili-clean="clean"] [class*="control-progress"],
[data-bili-clean="clean"] [class*="sending-area"],   /* 弹幕发送栏 */
[data-bili-clean="clean"] [title*="关闭网页"] …      /* 退出叉的文字兜底 */
```

再配合把播放器容器 `position: fixed; inset: 0` 铺满视口。

**清场是反复做的，不是一次性的**：进入全屏后哔哩哔哩才会**新建**那条
"按 ESC 退出全屏"的提示层——只隐藏一次根本抓不到它。
所以进入后的 3 秒内密集扫 5 次（80/300/800/1600/3000ms），之后**每秒复查一次**，
新冒出来的层会被立刻清掉。

## 几个实现细节

- **进入纯净模式会顺手进全屏**（等价于点播放器右下角那个全屏按钮）。
  浏览器要求全屏必须由**用户手势**触发——点按钮和按 `Alt+L` 都算，所以两条路都能进。
  万一被浏览器拒绝（例如从脚本里触发），会自动退回"网页全屏"，功能不受影响。
- **按钮会跟着全屏搬家**：全屏状态下浏览器只渲染全屏元素及其子树，
  按钮若还挂在 `body` 上就会"消失"、没法再点它退出。所以进出全屏时按钮会被重新挂载。
- **退出是两步走的**：先退出全屏，再还原 DOM——反过来会闪一下"半残"的页面。
- **Esc 一步还原**：在纯净模式里按 `Esc`，浏览器先退出全屏，代码随即把纯净模式也一起退出，
  两者永远同步（一个状态，不会出现"出了全屏但页面还是残的"）。

- **恢复是精确的**：被隐藏的节点都记下了原来的内联样式，退出时逐个还原，
  不会留下"某个区块再也出不来"的后遗症。
- **换视频自动退出**：哔哩哔哩是单页应用，检测到 URL 变化或播放器被重渲染挤掉时
  自动恢复，避免在新视频上停留在半残状态。
- **进出全屏时遮罩会搬家**（熄屏听剧用）：全屏只渲染全屏元素及其子树，
  遮罩必须挂进 `document.fullscreenElement` 才看得见。

改完在 `edge://extensions` 里点该扩展的 **「重新加载」**，再到页面上刷新即可，不用卸载重装。

## 说明

- 进入纯净模式会**自动进入真全屏**（等价于点播放器右下角那个全屏按钮）。
  若浏览器拒绝（例如不是由用户手势触发），会自动退回"网页全屏"，画面依然干净。
- **Edge 自己的全屏界面藏不掉**：全屏时把鼠标移到屏幕最顶部，浏览器会浮出它自己的
  标签栏（页面标题 + 关闭标签的叉）——那属于浏览器界面，网页脚本碰不到。
  哔哩哔哩自己那条顶部工具栏与"按 ESC 退出全屏"提示，已由本扩展隐藏。
- 某些 App 内嵌的浏览器**不加载 Chrome 扩展**，那里没有这个按钮；请在 Edge / Chrome 里用。

## 隐私

**不收集任何数据、不发起任何网络请求、不申请任何 `permissions`。**

唯一使用的本地存储是 `localStorage` 里一个用于记录"新版本提示是否已显示过"的键，
只留在你自己的浏览器里。详见 [PRIVACY.md](PRIVACY.md)。
