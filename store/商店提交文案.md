## 详细描述（可整段粘贴）
```
给哔哩哔哩网页版加一个「一键纯净模式」：点一下，页面只剩视频画面，并自动进入全屏。

【它做了什么】
· 隐去播放器内的进度条、音量条、弹幕发送栏与弹幕设置栏
· 隐去播放器外的顶部导航、右侧推荐、下方评论区、侧栏等一切页面装饰
· 自动进入全屏，视频铺满整个屏幕
· 再点一下（或按 Alt+L / Esc）全部原样恢复

【几个好用的细节】
· 鼠标不动 3 秒，连按钮一起隐去，画面真的只剩视频；鼠标一动按钮就回来
· 纯净模式下按 D：可以单独把弹幕也隐掉 / 显回来（默认保留弹幕）
· 换视频自动退出纯净模式，不会在新视频上停留在半残状态
· 还原是精确的：退出时逐项恢复，不会留下"某个区块再也出不来"

【附赠：熄屏听剧】
按 Alt+; 可以整页纯黑、视频继续播放，适合躺着听剧听歌；Esc 退出。

【它不做什么】
不收集任何数据、不联网、不修改哔哩哔哩的任何设置、不注入广告。
实现方式是纯本地的前端样式与 DOM 处理。

【适用】
Edge / Chrome 等 Chromium 内核浏览器，支持 www.bilibili.com、live.bilibili.com 等各站点。
```
